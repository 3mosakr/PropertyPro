# PropertyPro

##Real Estate Marketing Application (API)

- Developed a .NET Core application for marketing real estate units.
- Utilized Entity Framework Core for data access and SQL Server as the database.
- Implemented an API for data provision and user interaction.
- Using Identity, Added Authentication (Bearer), Added JWT Token, Authorizations (Roles).
- Configurations using Fluent API, Endpoints of Operations, Allow CORS.
- Create Services Like Upload Images, Filters, Database.
